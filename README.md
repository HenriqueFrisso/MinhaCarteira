# Minha Carteira

Base React + Vite para análise de investimentos, com persistência local, cadastro de ativos e domínio financeiro independente da interface.

## Executar

```bash
npm install
npm run dev
```

## Testar

```bash
npm test
```

O aplicativo inicia sem ativos ou dados demonstrativos. As cotações são informadas manualmente; ainda não há integração com API de mercado.
